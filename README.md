# Modern-Asteroids

## Description

A classic Asteroids arcade game built with Python and Pygame that has modern features added!
**Work in Progress (WIP)**.

## Requirements

- Python 3.13 or higher
- Pygame 2.6.1

## Running the Game

```bash
python main.py
```
